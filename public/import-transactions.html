Accepted columns

Header names are case-insensitive; spaces become underscores.
transaction_id *Unique transaction reference
merchant_id *Merchant reference
amount *Positive transaction amount
currency *3-letter currency such as SGD
transaction_type *online or face_to_face
payment_method *Visa, Mastercard, Alipay, WeChat Pay, GrabPay, ShopeePay, PayNow, or SGQR
txn_time *Valid date and time
terminal_idRequired when transaction_type is face_to_face
ip_addressRequired when transaction_type is online
countryDefaults to Singapore if omitted
transaction_statusOptional; defaults to success
customer_risk_profileOptional: low, medium, or high; defaults to low
masked_payment_refGenerated safely if omitted
payment_gateway_refGenerated safely if omitted
card_binOptional card metadata
masked_card_numberOptional masked PAN
card_presenceOptional card-present indicator
ip_countryOptional country derived from IP verification
ip_country_verifiedOptional Yes/No or 1/0 verification indicator
source_typeAssigned automatically as manual or excel_upload; do not add it to the file
